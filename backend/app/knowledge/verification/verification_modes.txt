Verification Modes and Gateway Network (SIH26100)

Verification Modes:
1. LIVE API: Direct live query to government portal database.
2. SANDBOX CONNECTOR: Simulated sandbox gateway mimicking live API schema.
3. DOCUMENT CONSISTENCY: Cross-document OCR comparison (e.g. GST Cert vs Bid Form name match).
4. MANUAL REVIEW: External source unavailable; requires officer inspection.
5. UNAVAILABLE: Government endpoint currently unreachable.
