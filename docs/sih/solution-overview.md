# 💡 BodhZ Solution Overview

BodhZ is an integrated sovereign decision support system engineered for public procurement authorities under **Smart India Hackathon 2026 (SIH26100)**.

### Core Value Propositions
- **85% Reduction in Evaluation Time**: Automated 13-gateway checks replace days of manual portal lookup.
- **100% GFR 2017 Legal Integrity**: Human Procurement Officers retain sovereign final qualification discretion.
- **Zero-Trust Auditability**: Every document, OCR extraction, and gateway check is sealed with SHA-256 hashes.
- **Role-Aware Workspaces**: Specialized portals for Central GeM Officers, State Department Officials (DTE Maharashtra), and Bidders.
